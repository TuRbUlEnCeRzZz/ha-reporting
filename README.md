# HA Reporting 0.1.0-beta.19

Archive de développement pour Home Assistant OS.

Beta.19 consolide l’interface et les périodes : navigation principale par onglets, en-tête compact, libellés français corrigés et heure de début de journée configurable par rapport (par exemple 05:30 → 05:30 pour EMHASS).

Le pipeline beta.18 reste disponible : automatisations internes, analyse IA, PDF natif local, export Paperless-ngx et notification Home Assistant.

Voir `ha-reporting/README.md`, `ha-reporting/DOCS.md` et `VALIDATION-beta19.md`.
