# HA Reporting 0.1.0-beta.20

Archive de développement pour Home Assistant OS.

Beta.20 améliore la précision des statistiques de puissance, l'intégration visuelle avec les thèmes Home Assistant / Liquid Glass et clarifie l'interface : onglet **Données**, duplication de rapports et destinations d'export déplacées dans **Paramètres**.

Les automatisations peuvent désormais notifier par notification persistante, entité `notify.*` (smartphone, etc.) et TTS via une entité `tts.*` + un lecteur `media_player.*`.

Le pipeline complet reste disponible : calcul, analyse IA, PDF natif local, export Paperless-ngx et notifications.

Voir `ha-reporting/README.md`, `ha-reporting/DOCS.md` et `VALIDATION-beta20.md`.
